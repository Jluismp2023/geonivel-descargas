# GeoNivel Pro · Descargas

Página: https://jluismp2023.github.io/geonivel-descargas/

El APK de Android está en [Releases](https://github.com/Jluismp2023/geonivel-descargas/releases).

GeoNivel Pro es una libreta de nivelación geométrica para Android: H+I y cotas, cierre con tolerancia, control de tubería y bordillos contra diseño, PDF y Excel. Funciona sin internet y guarda los datos solo en el teléfono. Próximamente en Google Play.
